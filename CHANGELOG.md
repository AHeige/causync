# Changelog

## 0.1.0-alpha.1 — Unreleased

- Initial standalone prerelease of the causal journal with explicit pending, accepted, confirmed, failed, conflict, superseded and uncertain phases; React maps protocol uncertainty to a `needs-attention` presentation state.
- Per-resource ordering, repeated-input policies, selective overlays, read coverage and safe retry identity.
- Standard Schema contracts, versioned manifests, typed catalog generation and finite-JSON recovery format v1.
- React, SWR and TanStack Query adapters with scoped ownership and unstyled devtools.
- Durable recovery, mutation-status lookup, opt-in offline replay and multi-tab coordination contracts.
- Host conformance CLI, AI instructions and independent packed-install verification of every public entrypoint.

This prerelease is published under the npm `next` tag. No compatibility with a stable `1.x` API is claimed yet.
